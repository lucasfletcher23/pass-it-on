# Pass It On

**Calgary's hockey gear exchange — built so the cost of a starter set never decides who gets to play.**

A community-driven platform for Calgary families to buy, sell, donate, and receive used hockey gear. Built to keep more kids on the ice.

## What this is

- **Marketplace** — buy and sell used youth hockey gear at fair prices
- **Free Gear Program** — donated gear matched to Calgary families who can't afford a starter set
- **Calgary-first** — built by a local hockey player, for the local hockey community

## Built with

- React + Vite
- Tailwind CSS
- lucide-react icons

## Run locally

```bash
npm install
npm run dev
```
